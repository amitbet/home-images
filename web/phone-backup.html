Open phone setup on this device
  1. Install PhotoSync. SFTP and automatic transfers may require a paid license.
  2. On iPhone:

    Save the file, then use Share → PhotoSync to import it. If import is unavailable, use the settings below.

  3. On Android: open PhotoSync → Configure → FTP → Add, choose SFTP and copy these settings.

Compare the server fingerprint when PhotoSync first asks you to trust the server.

Turn on automatic uploads

First send a test photo using Send → New → FTP. Then choose this destination under PhotoSync's Autotransfer settings. Use original quality, disable Delete after transfer and Allow overwrite, and disable Transfer to Temporary File.

Uploads stay in this phone's separate folder. Deleting photos from your phone does not remove server copies. Interrupted transfers must be retried; completed originals cannot be overwritten.

Videos are stored alongside photos; supported images appear in the photo browser.
