Connecting to Home Images

CONNECT AN ANDROID PHONE

A few steps. Then automatic.

  1. Install Syncthing-Fork

    Get it from F-Droid ↗ or download an Android APK ↗. Allow access to your photos and videos. There is no paid transfer plugin.

  2. Scan the receiver QR

    In Syncthing-Fork, open Devices → + → scan QR code. Scan the code shown here, name the device Home Images, and save. Use the scanner inside Syncthing-Fork.

  3. Approve your phone below

    Match the request’s device ID with Show device ID in your phone app, enter a name, then choose Approve phone.

  4. Share your Camera folder

    In the phone app, add or edit a folder, select DCIM/Camera, set its type to Send Only, and share it with Home Images. Choose Back up this folder below when the offer appears.

Keep backups running

Keep the app allowed to run in the background. Choose Wi-Fi only in its run conditions if you prefer. The phone and Home Images must both be online.
